# Standard Operating Procedure: Turbine Maintenance

Section 1: Pre-Maintenance Isolation
Ensure all breaker switches are tagged and locked out according to OSHA 1910.147.

Section 2: Bearing Inspection
Measure axial vibration using calibrated accelerometers. If RMS exceeds 4.5 mm/s, replace bearing assembly.

Section 3: Post-Maintenance Verification
Run idle test for 30 minutes. Monitor thermal escalation.
